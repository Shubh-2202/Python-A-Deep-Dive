# All about Python

This repository contains my Python learning journey and the code and Jupyter notebooks I have practised while studying Python. I am using it to keep my notes, examples, and practice work organised in one place.

## Topics I have studied and practised

- **Python Basics** — introduction, prerequisites, variables, data types, and operators
- **Data Structures** — lists, tuples, sets, dictionaries, and practice with `map()` and `filter()`
- **Loops**
- **Functions** — regular functions and lambda functions
- **Exception Handling**
- **File Handling** — reading, writing, and working with paths
- **OS Library** — basic operating-system and directory operations
- **Packages and Modules** — importing modules and creating simple functions
- **CSV** — basic reading and writing with Python's built-in `csv` module

## How to use

1. Clone or download this repository.
2. Open the folder in VS Code or another Python editor.
3. Run `.py` files with Python 3.
4. Open `.ipynb` notebooks in Jupyter Notebook, JupyterLab, or VS Code with the Jupyter extension.

For a Python file, you can run:

```bash
python filename.py
```

Some practice files use relative paths, so run them from the appropriate folder. The notebooks are learning/practice material and may need to be run cell by cell.
